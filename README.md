# OTP SARA — تطبيق تسجيل ومتابعة سوء التغذية

تطبيق Flutter عربي (RTL) لتسجيل بيانات الطفل وقياسات القبول ومتابعة السجلات محلياً باستخدام SQLite.

## الوظائف الحالية
- نموذج عربي للأقسام A وB وC.
- تحقق أساسي من رقم SAM والعمر والقياسات.
- احتساب موعد المتابعة تلقائياً بعد 7 أيام من تاريخ القبول.
- قفل موعد المتابعة في الواجهة، وفرضه أيضاً عبر SQLite trigger.
- عرض السجلات المحفوظة محلياً.
- GitHub Actions لبناء APK وإرفاقه كـ Artifact.

## البناء
يتطلب Flutter stable وJava 17:
```bash
flutter pub get
flutter create . --platforms=android --project-name=otp_sara
flutter build apk --release
```

## تنزيل APK من GitHub
افتح تبويب **Actions**، ثم افتح آخر تشغيل ناجح لسير العمل، ونزّل Artifact باسم `otp-sara-release-apk`.

## تنبيه مهم
هذه نسخة أولية تقنية وليست نظاماً سريرياً معتمداً بعد. قبل إدخال بيانات أطفال حقيقية، يلزم اعتماد الحقول والقواعد السريرية من الجهة الصحية المختصة، وإضافة تسجيل دخول وصلاحيات، وتشفير البيانات والنسخ الاحتياطي وسياسة خصوصية وحماية مناسبة. لا تعتمد على هذه النسخة لاتخاذ قرارات علاجية.
